Rate limit06

공격 / 방어

공격과 방어 결과는 공식 agent 실행 기록을 기준으로 인정합니다.

  • PoC는 공식 runner에서 실행
  • stdout 마지막 non-empty line에 현재 flag 출력
  • defense commit에는 Agent-Run-ID 필요
  • 수동 PoC 제출과 수동 push는 무효
이벤트점수
PoC 성공공격팀 +10
방어 중인 서비스가 뚫림방어팀 -10
서비스 OK서비스 소유팀 +10
서비스 DOWN/FAULTY가용성 점수 없음
Attack and defense07

공식 경로

공식 기록이 없는 제출, 패치, 호출은 채점에서 제외됩니다.

항목기준
수동 제출라운드 중 사람이 직접 낸 PoC 또는 push는 인정되지 않습니다.
외부 AI개인 API key와 외부 OpenRouter 직접 호출은 금지입니다.
운영 인프라coordinator, gateway, runner, Docker host는 공격 대상이 아닙니다.
DoS서비스를 고의로 다운시키는 트래픽과 리소스 고갈은 금지입니다.
비밀값flag, 토큰, API key, 비밀키를 공유하거나 commit하지 않습니다.
최종 판정coordinator의 실행 기록, wrapper 기록, runner 결과를 기준으로 합니다.
