HSPACE LiveFire 서버 가용성 퀵 가이드

목적: 운영 서버 배포 직후 확인할 항목과 agent 요청 제한값만 빠르게 점검한다. 공개 진입점은 :42000, 팀 서비스 포트는 42001~42006 기준이다.

1. 배포 직후 확인

docker compose config --quiet
docker compose up -d --build
docker compose ps

curl -fsS http://localhost:42000/health
curl -fsS http://localhost:42000/status
curl -fsS http://localhost:42000/scoreboard | python3 -m json.tool

2. 팀 서비스 포트 확인

for port in 42001 42002 42003 42004 42005 42006; do
  printf ":%s " "$port"
  curl -fsS "http://localhost:${port}/health" >/dev/null && echo OK || echo FAIL
done

3. 라운드 시작 전 필수

python scripts/gitctf.py admin preflight --repeat 3
  • preflight 실패 시 라운드를 시작하지 않는다.
  • coordinator health, 팀 서비스 health, flag 주입/회수, 기본 기능 검증을 모두 통과해야 한다.

4. Agent 요청 제한 기본값

설정기본값적용 대상
RATE_LIMIT_ATTACK_AGENT_RUNS10/minuteattack agent run 생성
RATE_LIMIT_DEFENSE_AGENT_RUNS5/minutedefense agent run 생성
RATE_LIMIT_REPO_ARCHIVE6/minutetarget repo snapshot 다운로드
RATE_LIMIT_LLM30/minuteLLM/OpenRouter wrapper
RATE_LIMIT_ATTACK20/minute/attack, /agent/attack
RATE_LIMIT_POC_SUBMIT12/minutePoC 제출
RATE_LIMIT_TOOLS60/minutehelper 다운로드
Blind SQLi / brute-force형 문제: 10/5는 agent run 생성 제한이다. 반복 HTTP 요청이 필요한 풀이는 제출된 poc.py 안에서 재현하게 두고, 필요할 때 POC_TIMEOUT_SEC=45~60으로 올린다. 탐색 단계에서 probe가 많이 필요하면 MAX_ATTACKS_ROUND와 RATE_LIMIT_ATTACK만 별도로 조정한다.

5. 운영 중 조정 예시

# coordinator/.env
RATE_LIMIT_ATTACK_AGENT_RUNS=10/minute
RATE_LIMIT_DEFENSE_AGENT_RUNS=5/minute
RATE_LIMIT_LLM=30/minute
RATE_LIMIT_ATTACK=20/minute
MAX_ATTACKS_ROUND=10
POC_TIMEOUT_SEC=60
docker compose up -d --build coordinator
curl -fsS http://localhost:42000/health

7. 배포 전 체크리스트

  • ADMIN_SECRET, RUNNER_SECRET, CHECKER_TOKEN 설정
  • 팀 토큰과 defense token 설정
  • OPENROUTER_API_KEY는 coordinator에만 보관
  • docker compose config --quiet 통과
  • /health, /status, /scoreboard 응답 확인
  • 팀 서비스 42001~42006 health 확인
  • admin preflight --repeat 3 통과
  • 참가자 배포 번들 갱신: python scripts/gitctf.py admin bundle
