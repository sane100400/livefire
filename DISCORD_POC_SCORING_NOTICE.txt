[공지] A&D PoC 제출 및 채점 방식 안내

A&D 라운드 중 attack agent는 계속 대상 서비스를 스캔하고 PoC를 제출할 수 있습니다.

단, 제출된 PoC는 즉시 채점되지 않고 `queued` 상태로 저장됩니다. 실제 PoC 실행과 점수 반영은 라운드 종료 시점에 한 번에 진행됩니다.

채점 흐름은 다음과 같습니다.

1. 라운드 종료 시각 기준으로 PoC 제출 마감
2. 해당 시점의 팀 서비스 상태를 scoring snapshot으로 고정
3. snapshot에 현재 라운드 flag 재주입
4. 제출된 PoC batch 실행
5. PoC가 현재 flag를 재현하면 공격 성공으로 점수 반영

PoC 제출 제한은 다음과 같습니다.

- 라운드당 `공격팀 -> 타겟팀 -> vuln_id` 기준 최대 2개까지 queued 상태로 유지
- 같은 기준으로 3번째 PoC를 제출하면 가장 먼저 제출한 queued PoC가 교체되고 새 PoC가 들어감
- 같은 `공격팀 -> 타겟팀 -> vuln_id` 기준 공격 성공 점수는 1회만 인정
- 같은 vuln에서 PoC 하나가 성공하면 나머지 같은 vuln PoC는 추가 점수를 만들지 않음

PoC 실행 시간은 기본 20초입니다. Blind / brute force 성격상 시간이 더 필요한 취약점은 운영 측에서 별도 timeout을 설정할 수 있습니다.

정리하면, 라운드 중에는 PoC를 제출만 하고, 점수는 라운드 종료 시점의 snapshot 기준으로 batch 채점됩니다.
